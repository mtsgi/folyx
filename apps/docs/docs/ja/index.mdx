## インストールして、画面の状態を読み取る [#install]

折りたたみ画面では、アプリが使える表示領域が複数に分かれることがあります。Folyxは、端末の折りたたみ状態、表示領域、その並び方をまとめて扱えるTypeScriptライブラリです。

フレームワークを使わないアプリでも利用できます。まずはパッケージを追加して、画面の状態を読み取ってみましょう。

<PackageInstall packages={["@folyx/core"]} />

```ts
import { createFolyx } from "@folyx/core";
const folyx = createFolyx();
const unsubscribe = folyx.subscribe((state) => {
  console.log(state.posture.value, state.layout, state.segments.items);
  console.log(state.availability, state.segments.source);
});
const current = folyx.getSnapshot();
unsubscribe();
```

`subscribe()`を呼ぶと、その時点の状態と、それ以降の変化を受け取れます。状態の変化を受け取り続けることを「購読」と呼びます。監視が不要になったら、戻り値の`unsubscribe()`を呼んで購読を解除します。

snapshotは、読み取った時点の状態をまとめたオブジェクトです。ブラウザから情報を取得できない場合も、その状況を確認できます。表示領域を取得できず、viewportの寸法がわかっている場合は、viewport全体を代わりの領域として返します。この代わりの値を「フォールバック」と呼びます。

詳しい使い方は[Core API](/core)、Vueとの連携は[Vueガイド](/vue)を参照してください。実機なしで画面の形を試すには、[Mock Provider](/providers)を使えます。APIの役割や値の扱い方は、[設計思想](/philosophy)で説明しています。

現在のバージョンは**0.1.0**です。対応する座標系とフォールバックの条件は、[座標系と互換性](/coordinates)を参照してください。
